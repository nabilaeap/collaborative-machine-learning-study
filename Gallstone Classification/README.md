# Gallstone Disease Classification

## Overview
This project explores machine learning approaches for classifying gallstone disease cases using clinical data.

The study compares:
- Logistic Regression
- Decision Tree

## Objective
To evaluate classification performance and understand model behavior on medical datasets.

## Methods
- Data preprocessing
- Feature preparation
- Model training
- Performance evaluation

## Results
Model performance was evaluated using:
- Accuracy
- Confusion Matrix
- Classification metrics
